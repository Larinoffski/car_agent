# car_agent

Short description of the project.

## Getting started

Prerequisites: Docker with Compose v2, `make`.

```sh
mkdir -p ~/.config/car_agent
cp envs/local.env.example ~/.config/car_agent/local.env   # fill in local secrets
make up
```

Environments and secrets: [envs/README.md](envs/README.md). `make help` lists all targets.
